# Microsoft Technical Support Analytics

## Project Overview
Microsoft Technical Support Analytics is an interactive Power BI dashboard project designed to analyse customer support operations, ticket resolution performance, agent productivity, and customer satisfaction.

The project uses data analytics and visualisation to turn support ticket data into meaningful business insights.

## Objectives
- Analyse overall support ticket volume and status.
- Monitor SLA performance and resolution time.
- Evaluate support agent productivity.
- Understand customer satisfaction and ratings.
- Compare ticket trends across different products.

## Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- Data Modelling
- Data Visualisation

## Dashboard Pages

### 1. Executive Overview
Provides a high-level view of support operations, including:
- Total Tickets
- Open Tickets
- Closed Tickets
- SLA Percentage
- Average Resolution Hours
- Average Customer Rating
- Monthly Ticket Trends
- Ticket Status Breakdown

### 2. Agent Performance
Analyses individual support agent performance through:
- Tickets Handled by Agent
- Average Customer Rating by Agent
- Average Resolution Hours by Agent
- SLA Performance by Agent
- Agent Performance Comparison

### 3. Customer Experience Analysis
Focuses on customer satisfaction through:
- Average Customer Rating by Product
- Customer Rating Distribution
- Average Customer Rating by Team
- Customer Satisfaction Trend Over Time
- Customer Rating by Support Agent

### 4. Product & Support Analysis
Provides product-level support insights through:
- Total Tickets by Product
- Ticket Status by Product
- Average Resolution Hours by Product
- SLA Performance by Product
- Monthly Ticket Trend by Product

## Interactive Features
The dashboard includes interactive slicers for filtering and exploring data by:
- Product
- Team
- Support Agent
- Experience Level
- Ticket Status
- Date
